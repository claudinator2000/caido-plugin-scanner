# Security policy

Do not disclose suspected vulnerabilities, credentials or sensitive data in a
public issue, discussion or pull request.

Use GitHub's private vulnerability-reporting or security-advisory channel when
it is enabled. Otherwise contact the maintainer through a private channel listed
in the repository README. If no private channel is available, report only that
a private contact path is needed; do not include vulnerability details publicly.

A security report should identify the affected revision, expected and observed
behavior, reproduction conditions, impact and any known mitigations. Never use
real credentials or third-party data as proof.
